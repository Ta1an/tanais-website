# TANAIS — Psychological Support Center

A modern, responsive multi-page website developed for **TANAIS**, a psychological support center in Kazakhstan.

The project focuses on creating a clean and accessible digital experience through thoughtful UI/UX design, smooth animations, and intuitive navigation.

**[Live Website](https://tanais.com.kz)**

## Preview

![TANAIS Website Preview](./public/preview.png)

## Tech Stack

- **Nuxt 3** — Vue-based framework
- **Vue 3** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Styling and responsive layouts
- **Motion for Vue** — UI animations and page transitions
- **Lenis** — Smooth scrolling
- **Iconify** — Icon library

## Features

- **Responsive Design** — Adapted for desktop, tablet, and mobile devices.
- **Modern UI/UX** — Minimalist layouts, clear typography, and intuitive navigation.
- **Smooth Animations** — Scroll-triggered effects, staggered transitions, and interactive elements powered by Motion for Vue.
- **Smooth Scrolling** — Natural scrolling experience using Lenis.
- **Multi-page Architecture** — Dedicated pages for services, information about the center, educational materials, and contacts.
- **Reusable Components** — Modular component structure for consistency and maintainability.
- **SEO Optimization** — Page-specific metadata and semantic HTML.
- **Contact Integration** — Contact form and WhatsApp integration for convenient communication.

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

Generate the static production version:

```bash
npm run generate
```

The generated website will be available in the `.output/public` directory.
